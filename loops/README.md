# 🔁 Java Loop & Pattern Practice

This project contains beginner-level Java problems to practice **loops** (`for`, `while`) and **nested loops** for **pattern printing**.

---

## ✅ Topics Covered

- Basic loops
- Mathematical logic with loops
- Nested loops for pattern printing

---

## 📘 Problems Practiced

1. Print numbers from 1 to 20
2. Print even numbers from 1 to 20
3. Print sum of numbers till 100
4. Take user input and calculate sum from 1 to n
5. Count digits in a number
6. Reverse a number
7. Check if a number is a palindrome
8. Print Fibonacci series up to n terms
9. Find the factorial of a number
10. Q10 = Q14 (Pattern questions)

---

## 🛠 How to Run

- Use any Java IDE (like IntelliJ or Eclipse) or an online Java compiler.
- Paste the code into a `.java` file and run the `main()` method.

---

## 💡 Tip

To practice pattern questions, focus on:
- Outer loops for rows
- Inner loops for columns, spaces, or stars
