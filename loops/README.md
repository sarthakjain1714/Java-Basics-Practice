# 🔁 Java Loop Practice 

Welcome to my **Java Loop Practice Collection**!  
This project includes a series of beginner-to-intermediate level exercises using **loops** and **nested loops** to build strong foundational logic in Java.

---

## 📚 Topics Covered

- ✅ Basic `for` and `while` loops
- ✅ Nested loops for pattern printing
- ✅ Mathematical operations using loops
- ✅ Conditional logic inside loops

---

## 🧪 Questions Practiced

### 🔢 Basic Loop Questions

| No. | Description |
|-----|-------------|
| 1 | Print numbers from **1 to 20** |
| 2 | Print **even numbers** from 1 to 20 |
| 3 | Print the **sum of numbers till 100** |
| 4 | Take user input and **sum numbers from 1 to n** |
| 5 | Count the **number of digits** in a number |
| 6 | Find the **reverse** of a number |
| 7 | Check if a number is a **palindrome** |
| 8 | Print the **Fibonacci series** up to `n` terms |
| 9 | Find the **factorial** of a number |
